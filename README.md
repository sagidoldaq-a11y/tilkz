# TilKz AI

Қазақ тілін үйрететін платформа. Бірінші модуль: **оқу сауаттылығы** (НЗМ, БИЛ емтихандарына дайындалатын 4–6 сынып оқушылары).

Сайт: https://sagidoldaq-a11y.github.io/tilkz/

## Құрылымы

| Қалта / файл | Мазмұны |
|---|---|
| `index.html` | Сайттың өзі (автоматты құрастырылады, қолмен өзгертпеңіз) |
| `content/build_v1.py` | 1-нұсқаның тапсырмалар банкі: мәтіндер, сұрақтар, кілттер, дағды кодтары, түсініктемелер |
| `content/bank_v1.json` | Банктің JSON нұсқасы (`build_v1.py` жасайды) |
| `web/app.template.html` | Платформаның беті (дизайн және логика) |
| `web/build_public.py` | `index.html` файлын құрастырады |
| `docs/` | Мұғалімге арналған тексеру құжаттары |

## Жаңарту

```bash
python3 content/build_v1.py
python3 web/build_public.py
```
