# aitil

Қазақ тілін үйрететін платформа. Бірінші модуль: **оқу сауаттылығы** (НЗМ, БИЛ емтихандарына дайындалатын 4–6 сынып оқушылары).

Сайт: https://aitil.kz/ (визитка)  
Тест: https://aitil.kz/nzm-bil/

## Құрылымы

| Қалта / файл | Мазмұны |
|---|---|
| `index.html` | Визитка-бет (`web/home.html` көшірмесі, қолмен өзгертпеңіз) |
| `nzm-bil/index.html` | «НЗМ, БИЛ. Қазақ тілі» курсы (автоматты құрастырылады) |
| `web/home.html` | Визитка-беттің түпнұсқасы |
| `img/` | Фотосурет және сілтеме алдын ала көрінісі (og.jpg) |
| `content/build_v1.py` | 1-нұсқаның тапсырмалар банкі: мәтіндер, сұрақтар, кілттер, дағды кодтары, түсініктемелер |
| `content/bank_v1.json` | Банктің JSON нұсқасы (`build_v1.py` жасайды) |
| `content/build_l2_v1.py` | «Қазақ тілі (екінші тіл)» 1-нұсқасы: мәтіндер, сұрақтар, түсініктемелер, орысша аудармалар |
| `content/bank_l2_v1.json` | Екінші тіл банкінің JSON нұсқасы |
| `content/build_l1_v6.py` … `build_l1_v10.py` | «Қазақ тілі (бірінші тіл)» 6–10-нұсқалары (НЗМ үлгісінің құрылымы, мәтіндер ашық сайттардан) |
| `content/build_l2_v6.py` … `build_l2_v10.py` | «Қазақ тілі (екінші тіл)» 6–10-нұсқалары, орысша аудармасымен |
| `docs/suraqtar-klassifikatsiyasy.md` | НЗМ үлгісіндегі сұрақтардың классификациясы |
| `web/app.template.html` | Платформаның беті (дизайн және логика) |
| `web/kz0.html`, `web/kz0-hw0.html`, `content/kz0-hw0.json` | «Қазақша. Старт» курсы (тек орысша беттен): курс беті, ұпайлы үй тапсырмасы. Нәтижелер `attempts`/`answers` кестелеріне `kz0-hw0` банкімен жазылып, мұғалім кабинетінде көрінеді |
| `web/build_public.py` | `index.html` және `nzm-bil/index.html` беттерін құрастырады |
| `docs/` | Мұғалімге арналған тексеру құжаттары |

## Жаңарту

```bash
python3 content/build_v1.py
python3 content/build_l2_v1.py
python3 web/build_public.py
```

Мазмұн: Сағидолда Қ., «Тест жинағы. НИШ, БИЛ. Қазақ тілі», 2026.
